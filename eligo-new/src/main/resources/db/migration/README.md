# 数据库迁移目录

本目录用于保存经过确认的 Flyway 版本化数据库迁移脚本。当前仓库基线为 V1 至 V18：V1 至 V4 覆盖 M1 与企业基础，V5 至 V9 覆盖 M2 活动，V10 覆盖 M3 参与关系，V11 覆盖 M2 活动地点坐标，V12 覆盖 M3 活动报名性别与联系方式字段，V13 覆盖 M4 关注与动态，V14 覆盖 M4.1 推荐索引任务，V15 覆盖 M2 活动集合地点名称，V16 覆盖 M2 活动话题，V17 覆盖 M3 活动收藏，V18 覆盖 M3 活动评论。

当前保护规则：

- 所有环境默认关闭 Flyway 自动迁移；
- V1 至 V18 必须在隔离集成测试数据库中验证，数据库与并发测试不得连接个人业务库；
- 本地和生产环境仍默认关闭 Flyway 自动迁移；未经授权不得连接或修改现有 `eligo` 数据库；
- 迁移脚本确认后按 `V版本__说明.sql` 命名；
- 已执行的迁移不得修改，只能新增版本；本次已把未发布分支的迁移重编号为：M2 活动地点 V11、M3 联系方式 V12、M4 关注动态 V13、M4.1 推荐任务 V14、M2 地点名称 V15、M2 话题 V16、M3 收藏 V17、M3 评论 V18；
- 禁止在脚本中写入密码、密钥或测试业务数据。
